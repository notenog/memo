シナリオ紹介ページ ジェネレーター

マークダウンで本文を書き、パターンと差し色を選ぶと単体HTMLとして書き出せます。

このツールで書き出したHTMLを読み込むと、内容と設定を復元して再編集できます。設定は自動的にブラウザにも保存されます(画像を除く)。

一覧ページに表示される説明文です。

入力すると、左端のジャンルタブの下に「ハウスルール」タブが並んで表示され、クリックするとこのURLに飛びます(狭い画面では非表示になります)。空欄の場合は表示されません。

画像を挿し込みたい位置に {{img1}} {{img2}}... と書いてください(下の画像リストのタグをクリックでコピーできます)。

📝 マークダウン機能一覧

基本的な書き方

  • # タイトル … h1見出し
  • ## 見出し … h2見出し (カード型では自動で分割)
  • **太字** … 太字
  • *斜体* … 斜体
  • - リスト … 箇条書き

画像・コンテンツ埋め込み

  • {{img1}} {{img2}} … 下の「画像」欄でアップした画像を挿入
  • {{table}} … シナリオ情報テーブルを挿入

ハイライト(マーカー)

  • ==テキスト== … 差し色の蛍光ペン
  • ===テキスト=== … 黄色の蛍光ペン

注釈・説明ボックス

  • > [!NOTE]
    > 本文 … 水色の情報ボックス
  • > [!TIP]
    > 本文 … 緑のコツボックス
  • > [!WARNING]
    > 本文 … 黄色の警告ボックス
  • > [!DANGER]
    > 本文 … 赤の危険ボックス

インタラクティブなブロック

  • :::accordion
    タイトル | 本文
    ::: … 折りたたみボックス
  • :::card
    ## タイトル
    本文
    ::: … カードレイアウト (## で分割)
  • :::carousel
    {{img1}}
    {{img2}}
    ::: … 画像スライドショー

本文中に {{table}} と書いた位置にこの表が挿入されます。各行の項目名・内容を編集でき、✕ で削除できます。
